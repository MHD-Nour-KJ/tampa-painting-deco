# Tampa Painting Deco

Modern, responsive landing page for **Tampa Painting Deco LLC**, offering premier interior painting, exterior weather shield coatings, kitchen cabinet refinishing, and bespoke decorative finishes across the greater Tampa Bay area.

## Tech Stack
- **React 19** + **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**

## Features
- **Hero & On-Demand Booking**: Integrated location and service filter with customer satisfaction metrics.
- **Top Services Bento & Cards**: Distinctive 4-card service palette with smooth interactions.
- **Home Essentials Carousel**: Multi-service showcase with real project photography.
- **Bento Trust Grid**: Live neighborhood metrics, 24/7 availability, and contractor credentials.
- **Full-Width Parallax Scroll**: Screen-width architectural Florida home showcase.
- **Interactive Before & After Comparison**: Drag-to-reveal split slider highlighting real transformations.
- **Testimonial Deck**: Layered card deck customer review carousel.
- **Instant Price Estimator Modal**: Dynamic ballpark estimator with free in-home consultation booking.
- **Fully Responsive**: Optimized for Desktop, Laptop, Tablet, and Mobile with quick call actions.

## Getting Started

### Prerequisites
- Node.js 18+ or Bun

### Installation
```bash
bun install
# or
npm install
```

### Development
```bash
bun run dev
# or
npm run dev
```
Starts development server on `http://localhost:3001`.

### Production Build
```bash
bun run build
# or
npm run build
```
Builds production-ready assets into `dist/`.

### Deployment
Configured for zero-config deployment on [Vercel](https://vercel.com).
